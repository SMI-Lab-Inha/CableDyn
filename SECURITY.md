# Security policy

This policy tells you how to report a security vulnerability in CableDyn.

## Supported versions

Security fixes are released for the latest CableDyn version. Reproduce a report on
that version.

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Do not disclose a vulnerability in a public issue. Use GitHub's private reporting
form under **Security > Advisories > Report a vulnerability**. If the form is
unavailable, email `jaehoon.seo@inha.ac.kr` with the subject
`CableDyn security report`.

Include the CableDyn version or commit, operating system, compiler or Python
version, the smallest reproducer you can share safely, and the observed impact. We
acknowledge reports within 7 days, agree a disclosure schedule with the reporter,
and publish a fixed release and advisory when warranted.

Convergence problems, modelling limitations, and suspect results belong in the
public issue tracker unless they also present a security risk.
