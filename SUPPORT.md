# Getting help

CableDyn is maintained by SMI Lab, Inha University, on a best-effort basis. All
support is through public GitHub Issues, so that answers help the next user too.

1. **Read the manual first.** The
   [manual](https://cabledyn.readthedocs.io) covers installation, tutorials, every
   deck keyword and output channel, and a
   [troubleshooting](https://cabledyn.readthedocs.io/en/latest/troubleshooting.html)
   page that maps each error message to its fix.
2. **Search existing issues**, open and closed, at
   <https://github.com/SMI-Lab-Inha/CableDyn/issues>.
3. **Open an issue** with the matching template:

   | You have | Template |
   |---|---|
   | A crash, a wrong result, or a valid input that is rejected | Bug report |
   | A capability you need | Feature request |
   | A question about modelling, inputs, or outputs | Question |

   Attach the smallest deck that shows the problem and every file it references,
   and state the CableDyn version (`CableDyn_driver.exe --version`).

Security vulnerabilities are not reported in public; follow
[SECURITY.md](SECURITY.md). For questions about citing CableDyn or collaboration,
contact the maintainer at <jaehoon.seo@inha.ac.kr>.

The maintainers cannot review proprietary models or give design advice for a
specific project; CableDyn users remain responsible for their engineering
decisions.
